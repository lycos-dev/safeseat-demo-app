# SafeSeat UAT UX R2 — Seats visual/navigation refinement

Changes in this refinement:
- Replaced opaque white seat assignment boxes with translucent dark glass-style seat hotspots so the original car image remains visible.
- Added press-scale feedback to seat hotspots for a more interactive feel.
- Kept clear seat names and compact Tap affordances without covering the car artwork.
- Added a persistent Start Monitoring action bar above the tab navigation; users no longer need to scroll to discover the next step.
- Persistent action bar communicates whether seats still need assignment, how many are assigned, or whether monitoring is active.
- Replaced the bulky setup guide card with a compact two-step progress ribbon.
- Kept the previously approved functionality and wording changes from UAT UX R1.
